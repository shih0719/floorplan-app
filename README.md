# 平面圖設備標註與迴路對應 Web App

一個**平板可用的 Web 應用**，讓使用者在「平面圖」上標註設備、建立「設備 ↔ 迴路」對應關係，方便現場盤點與紀錄。

---

## 一、專案目標

- 取代紙本或 Excel 的設備／迴路對應紀錄
- 讓使用者在現場用平板就能快速、直覺地標註與紀錄
- 建立「平面圖 → 設備 → 迴路」之間的關聯，方便日後查詢與維護

---

## 二、需求清單

### 平面圖管理
- 上傳平面圖圖片
- 多平面圖／樓層／區域
- 編輯、刪除平面圖
- 平面圖可縮放、平移

### 設備標註
- 點平面圖新增設備
- 填寫名稱、編號、類型、備註
- 編輯、移動、刪除設備
- 設備標記隨縮放保持在正確位置

### 共用 Icon（畫面精簡）
- 同類型＋同座標設備共用一個 icon
- icon 右上角顯示數量
- 點 icon 彈出設備清單
- 清單中可個別編輯、新增、刪除設備
- 不需拆分功能

### 設備類型管理（自訂）
- 可自訂設備類型
- 每個類型可自訂 icon
- 每個類型可設定「迴路數量」

### 迴路對應
- 迴路管理（新增、編輯、刪除）
- 設備可指定所属迴路
- 從設備看迴路、從迴路看設備
- 依迴路篩選平面圖設備
- 每個平面圖各自有獨立迴路
- 建立設備時自動生成該類型的迴路（不自動分配）

### 圖層
- 設備與迴路分圖層
- 「迴路標籤」可切換顯示／隱藏

### 平板操作
- 觸控友善、按鈕夠大
- 操作步驟精簡

## 六、安裝與啟動

### 需求
- Node.js 24 以上（內建 `node:sqlite`）

### 安裝
```bash
cd C:\app
npm install
npm run install:all
```

### 啟動（開發模式）
```bash
npm run dev
```

- 前端：http://localhost:5173
- 後端：http://localhost:3001

> 若安裝失敗，請先清除 `server\node_modules` 與 `server\package-lock.json` 後重新安裝。

### 建置（供離線／單機執行）
```bash
npm run build
```
建置後，後端會直接提供前端（同一個 port）：啟動 `npm run dev:server` 後開啟 http://localhost:3001 即是完整 App。

## 八、平板離線使用

核心概念：**把伺服器直接跑在平板本機**，資料都存在平板上的 SQLite，因此「天生離線」，不需網際網路。

1. 先在電腦執行 `npm run build`（或直接把建置好的整個專案資料夾複製到平板）。
2. 在平板上安裝並執行 Node.js：
   - **Android 平板**：安裝 [Termux](https://termux.dev)，執行 `pkg install nodejs`。
   - **Windows 平板**：直接安裝 Node.js。
   - **iPad（iOS）**：目前無正式途徑執行 Node.js，此方案不適用。
3. 在專案資料夾啟動：`npm install && npm run install:all && npm run dev:server`
4. 平板瀏覽器開啟 `http://localhost:3001` 即可使用，離線可用。
   - 若要其他裝置連到此平板，改用平板在區域網路的 IP，例如 `http://192.168.x.x:3001`。

> 離線期間所有資料只存在該平板；如要換機或備份，請用「匯出／匯入」JSON 完整備份。

---

## 九、匯出／匯入

- **匯出**：平面圖列表右上「匯出全部」＝全部；每張平面圖卡片「匯出」＝單一。
- **格式**：JSON 完整備份（含平面圖圖片 base64、設備、迴路與其從屬關係）。
- **匯入**：點「匯入」選取先前匯出的 `.json` 檔即可還原。

## 十、主要操作流程

1. 上傳平面圖 → 建立樓層／區域
2. 點平面圖 → 新增設備（可輸入數量、自動命名）
3. 同座標同類型自動合併 icon，右上角顯示數量
4. 點 icon → 彈出清單 → 編輯個別設備或新增設備
5. 建立設備時自動在該設備下產生迴路（數量依設備類型，命名如 `3S5A-1-ch1`）
6. 切到「迴路」圖層，在左側選一個迴路 → 點平面圖，把它放到其負載（燈具）位置；放完自動跳下一個
7. 開啟「迴路標籤」在平面圖上顯示迴路標記
8. 匯出／匯入 JSON 完整備份；平板離線執行（見「八、平板離線使用」）
